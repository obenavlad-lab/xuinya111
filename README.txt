Запуск
======
Распакуйте архив, сохранив структуру:
index.html
models/model.glb

Откройте папку через HTTP-сервер (например, Live Server в VS Code),
либо разместите оба файла на статическом хостинге.
Прямое открытие file:// ограничивает загрузку внешнего GLB браузером.
Нужен интернет для загрузки three.js с CDN.

Весь HTML, CSS, JS и предоставленное изображение камуфляжа (встроено как data URI) находятся в index.html.
MODEL_URL, MAX_YAW, MAX_PITCH и SMOOTHING — в начале скрипта.
Движение мыши / касание управляет наклоном. После Tab доступны стрелки;
Escape возвращает модель в центр. Автоматического вращения нет.
На узких экранах модель уменьшается до полного размещения по ширине.

https://sketchfab.com/SeveN-Models
